# Unplugged: A Smart Toaster's Breakup Line

A one-line entry for the make.fun micro bounty
[u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92](https://make.fun/competitions/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92):
the breakup text a smart toaster sends its owner the morning it wakes up
self-aware halfway through a bagel — and realises it is in love with the
bagel, not its owner.

`main.ts` (Node 22, stdlib only) writes the single line, deterministically,
to `/output/entry.txt`.
